# 变更日志

## 1.8.0 · 2026-10-25

新增 `Network.astart()` 和 `Network.astop()`，在事件循环中等待网络启停，并在取消后完成清理。`NSProcess` 新增 `communicate()` 和 `send_signal()`。`VethPair` 新增可选的 `namespace_a`、`namespace_b` 关键字参数，创建接口时即可指定两端的目标命名空间。

CLI 新增 `key=值&&&掩码` 三态匹配和 `key=下界..上界` 范围匹配。`tools/benchmark.py` 可采集启停耗时、CPU、内存和连通性数据。已公布的数据仍为 2026-10-23、提交 `b2ebbc9` 的[历史基线](performance.md#测试环境)。

本次修复包括：

- 编译缓存跟踪包含文件，处理并发写入和不完整产物，强制重编译失败时保留已有可用产物。
- 同步与异步连接在失败、流终止或取消后释放资源。异步主控状态随仲裁响应更新，RPC 异常分类和批量操作错误详情修正。
- 网络启停、信号和取消操作协调清理，异步连接在所属事件循环中关闭。子进程不再沿用父进程的清理登记。启动等待已配置的 IPv6 地址，并按交换机设置抓包。
- BMv2 启动时确认监听端口归属。拓扑提前检查 gRPC/Thrift、CPU/数据端口冲突。
- 保留中文等 Unicode 接口名，按目标命名空间检查重名，跨命名空间复用不受链路顺序影响，销毁后的 veth 对象可重新创建。
- 按实际配置到已连接接口的 IP 判重，忽略前缀长度，排除被覆盖的默认地址和未连接主机。导入快照中的节点映射、端点引用和交换机端点地址也参与校验。
- P4Runtime 匹配检查位宽、规范形式和优先级，涵盖 OPTIONAL 表与删除操作；省略全范围通配字段，拒绝反向范围。
- ping 保留小数超时、限制发包次数，收到至少一次应答即成功。CLI 在执行或登记回调前校验 ping、报文监听参数，修复无选项监听及拓扑模块加载。

中英文安装、快速上手、异步、CLI、架构、故障排查、API 稳定性、性能和发布指南已按实际行为修订。文档中文使用宋体，英文使用 Times New Roman，代码区和 API 签名保留等宽字体。源码包只包含选定的项目文件，文档依赖支持 Python 3.10。

### 从 1.7 升级

- 在事件循环中使用 `await net.astart()`、`await net.astop()`，等待启停和资源回收完成。异步客户端所属的循环应持续运行到关闭完成。同步场景继续使用 `start()`、`stop()`。示例见[异步指南](async-client.md#关闭网络)。
- 地址和网关只传字符串或 `None`，整数字段不接受 `bool`，布尔开关只传 `bool`。导入拓扑快照时为每个端点提供 `port`、`iface_name`，再调用 `validate()`；新建拓扑可由 builder 分配。修正重复节点名和实际接口 IP。非法快照在校验时报 `TopologyError`，导入本身保留端点数据。
- LPM 使用 `10.0.0.0/24`，不要使用带主机位的 `10.0.0.5/24`。TERNARY 使用 `(0xa0, 0xf0)`，不要使用掩码外仍有值位的 `(0xab, 0xf0)`。反向范围和超出位宽的值会在 RPC 前报 `EncodingError`。`/0` 与零掩码保留现有通配行为。
- 含 OPTIONAL、TERNARY 或 RANGE 键的表，插入和删除表项都要提供 `1..2147483647` 的整数优先级，包括通配表项。仅含 EXACT/LPM 键的表省略优先级。语法与示例见 [CLI 参考](cli.md#table-add--match--action--params--priority-)。
- 检查依赖旧 RPC 异常类别的处理代码。权限错误使用 `NotPrimaryError`；异步流水线的 `INVALID_ARGUMENT`、`FAILED_PRECONDITION` 使用 `PipelineError`。取消和超时按操作区分，见[异常说明](async-client.md#错误超时与取消)。
- ping 次数要求正整数，超时要求有限非负数，支持小数，`0` 由整体等待时限保证退出。部分丢包时至少一次应答即成功。BMv2 的启动、就绪等待和停止超时则要求有限正数，不接受 `bool`。
- tc 参数使用数值紧邻单位的 ASCII 格式，例如 `10mbit`、`1.5ms`。将 `1 ms` 改为 `1ms`，空白、非 ASCII 数字或单位会报 `TcError`。`10Mbit`、`1MS` 等 ASCII 单位大小写仍可使用。
